Alfred’s Storybook

Open the website

The archive places index.html at the repository’s top level. Upload its extracted contents and keep Pages set to main / (root). After deployment, open the Storybook.

Save photos and entries

Choose Connect GitHub. Use a fine-grained token limited to this repository with Contents read/write access. The app saves originals to dated folders inside /media. Your token is kept in the current tab’s memory.

Shared sign-in

Complete the owner’s deployment in server/SETUP.md. This creates an HTTPS app URL with GitHub sign-in and owner-controlled viewer/contributor roles. Enter that URL in site-config.js to connect the Shared sign-in button. Until deployment, that button shows these setup instructions.

Controlled viewing

GitHub Pages makes published photos and entries public. For restricted access, serve the journal through the shared server using a private data repository, and remove the journal data from public Pages publication.
