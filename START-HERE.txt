ALFRED'S STORYBOOK — REMEMBER ME ON THIS COMPUTER

1. Upload index.html and site-config.js to the repository root.
   The empty site-config.js replaces the earlier shared-token configuration.
2. Wait for GitHub Pages deployment, then refresh with Ctrl+Shift+R.
3. Open Connect GitHub, enter your repository token, keep
   Remember me on this computer checked, and connect.

This browser will reconnect automatically after you leave and return.
Disconnect removes the saved token from this browser. Uncheck Remember me
before connecting to use the current visit only. Reconnecting while unchecked
removes any previously saved connection.

The token is saved in this browser's IndexedDB storage. It is not written to
site-config.js, journal.json, backups or the GitHub repository. Browser data
clearing, private browsing, token expiration or revocation requires reconnection.
Use a computer you trust. Other browsers/devices need their own connection.

No token is included in this archive. If you published a token in an earlier
site-config.js, revoke it and use a replacement; older commits may retain it.

Existing journal.json and photographs are excluded from this update.
No Cloudflare deployment or shared-token configuration is used.
