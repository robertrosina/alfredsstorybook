ONE-TIME OWNER SETUP
1. Open Site settings on the website.
2. Enter a NEW fine-grained token restricted to this repository, with Contents
   read/write access. Revoke the token previously shared in chat.
3. Click Connect repository.
4. Reopen Site settings and choose Download shared settings.
5. Upload the downloaded site-config.js to the repository root, replacing
   the blank copy. Wait for Pages to redeploy.

Now everyone visiting the site chooses a name and can edit and upload.
Returning visitors choose a name again; the repository reconnects automatically.
No Cloudflare, backend or browser token remembering is required.

The user selector records the author of new entries. It is not authentication.
Anyone can select any name, and anyone who can read the published site/config
can use the shared token's permissions, including outside this interface.
Keep the token limited to this one repository. Replace site-config.js when
the token expires. Do not use this arrangement for restricted private access.
